
# Sakila DVD Rental Business Analysis | MySQL
Analyzed a relational DVD rental database using SQL to evaluate customer behavior, film performance, rental activity, revenue, and store performance.
Applied multi-table JOINs, aggregations, HAVING, CASE, subqueries, CTEs, and window functions to identify high-value customers, popular films, category performance, and revenue trends.
Developed customer segmentation and ranking analyses using CASE, RANK(), DENSE_RANK(), ROW_NUMBER(), and PARTITION BY.
Created reusable SQL views and demonstrated indexing concepts to support analytical queries and database performance.
